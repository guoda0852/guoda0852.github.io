④ 格式速查

sites（点播源）字段
字段说明
key源唯一标识，勿重复
nameApp 首页显示的名称
type0=采集站 XML 接口（苹果CMS）· 1=采集站 JSON 接口 · 3=spider jar（api 填 csp_类名）
apitype=3 时填 jar 内的类名（如 csp_Demo → com.github.catvod.spider.Demo）；type=0/1 时填采集接口地址
ext扩展配置（json 地址或参数），可空
searchable1=参与全局搜索，0=不参与
quickSearch1=支持快捷搜索
filterable1=支持分类筛选
lives（直播源）字段
字段说明
name分组显示名称
type0=外链 txt/m3u
url频道列表文件地址（txt：名称,播放地址 每行一个；分组行以 ,#genre# 结尾）
epg节目单地址（可空）
parses（解析接口）字段
字段说明
name接口名称
type0=Web 聚合 · 1=Json 聚合
url接口地址（把视频页地址拼在 ?url= 后面）
⚠️ 本站是公开仓库，只放演示源与格式文档。正式采集源建议放到你自己的甲骨文服务器上私密托管，不要进公开仓库。

⑤ 更新流程

  1. 改 box.json / live.txt / jar/
  2. push 到 GitHub，Pages 自动重新部署（约 1 分钟）
  3. App 端：设置 → 刷新配置，即生效
